# WELCOME TO JOVIAL-TEXT

    Note: This app is still under development


To try it, execute the following command:
```bash
mkdir jovialText && cd jovialText && curl -o run-jovial-text.sh -s https://raw.githubusercontent.com/suryaanshrai/jovialText/refs/heads/v2/run-jovial-text.sh && bash run-jovial-text.sh
```


To try it in dev mode, execute the following command:
```bash
git clone -b v2 git@github.com:suryaanshrai/jovialText.git && cd jovialText && docker compose -f docker-compose-dev.yml up
```
